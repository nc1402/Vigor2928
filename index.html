AI Router · Nền tảng 1 — AI Gateway

AI Gateway: Quản lý chi phí AI tập trung ngay trên Router

Không cần mua thêm phần mềm. Vigor2928 đứng giữa nhân sự và OpenAI, Claude, Gemini, Qwen, Llama… để kiểm soát, phân bổ và ghi log.

Nhân viên
Virtual Key→Vigor2928 AI Gateway→OpenAI / Claude / Gemini
  • Quota Profile: Giới hạn token theo ngày / tháng cho từng team. Ví dụ: Dev 1.000.000 / ngày, Content 500.000 / ngày, Thực tập 100.000 / ngày.
  • Chống Shadow AI: Chặn AI không được cấp phép qua DNS & SNI inspection. Biết ai dùng gì, lúc nào, tốn bao nhiêu token.
  • Bảo mật: SSL/TLS + Certificate. Làm việc LAN / VPN / WAN đều được quản lý đồng bộ.
  • Trải nghiệm: Dev chỉ cần gắn Virtual Key vào VS Code, Claude Code, Cursor là chạy.

AI Router · Nền tảng 2 — MCP Server

MCP Server: AI đồng hành quản trị Router

Kết nối Claude CLI / Codex vào Vigor2928 qua MCP (cổng 3456). Ra lệnh bằng ngôn ngữ tự nhiên, router tự đọc và thay đổi cấu hình — có Token phân quyền.

Bấm 1 lệnh ở trên để xem AI trả lời như thế nào →
  • 3 bước setup: Bật MCP Server → Tạo Access Token → Thêm Token vào Claude / Codex.
  • An toàn: Tối đa 8 Token / router, mỗi Token gắn 1 Role, Token chỉ hiện 1 lần.

Multi-WAN · SLA

3 WAN Load Balancing & SLA: Kết nối không đứt quãng

Gộp băng thông, chia tải thông minh, Failover tức thì. VoIP và ứng dụng nghiệp vụ luôn đi qua WAN đạt chuẩn — vì SLA đo chất lượng thật, không chỉ “còn sống”.

SLA Load Balancing

Chia tải theo độ trễ, jitter, mất gói — đường nào tốt thì gánh nhiều hơn.

SLA Policy Route

Ép Zoom / VoIP / ERP đi WAN tốt nhất. Web thường đi WAN còn lại.

Không. Doanh nghiệp vẫn mua API Key chính thức từ OpenAI / Claude / Gemini. AI Gateway là lớp kiểm soát ở giữa: cấp Virtual Key, giới hạn quota, ghi log, chặn Shadow AI. Bạn tiết kiệm vì không bị vượt quota, không phải vì không trả tiền API.
Hiện AI Gateway chưa tự động chuyển sang Key dự phòng. An Phát sẽ tư vấn chia quota theo team + cảnh báo sớm để bạn nạp / phân bổ lại trước khi gián đoạn. Đây là điểm presale sẽ nói rõ ngay từ đầu, không để bạn bất ngờ.
Có, nếu phân quyền đúng. Mỗi router tối đa 8 Token, mỗi Token gắn 1 Role, Token chỉ hiện 1 lần. An Phát khuyến nghị chỉ bật MCP từ LAN, không mở WAN khi không cần, và xóa Token không dùng.

Chưa — đây là tính năng của bản firmware tương lai. An Phát cam kết không nói như đã có sẵn và sẽ cập nhật cho bạn khi DrayTek phát hành chính thức.
